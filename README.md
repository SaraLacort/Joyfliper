# Joyfliper

## Integração GameZ

O jogo **Cobrinha** foi reimplementado em TypeScript para o Joyfliper, usando como referência a mecânica do Snake Game do projeto [GameZ, de Explorer-O7](https://github.com/Explorer-O7/A-Mini-Game-Website-GameZ). O README do projeto de referência declara licença MIT, mas não foi localizado um arquivo LICENSE separado nesta inspeção. A implementação do Joyfliper utiliza desenhos próprios em Canvas e não importa imagens, áudio ou outros recursos gráficos do GameZ. Antes de copiar qualquer arquivo do GameZ diretamente, confirmar a licença e preservar seus avisos de autoria.
