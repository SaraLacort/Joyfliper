# Joyfliper Native (experimental)

Nova base Java + libGDX em desenvolvimento. A versão Vite/Capacitor permanece na raiz e na branch `backup-joyfliper-vite`.

## Requisitos
- JDK 17 (Gradle toolchain)
- Android SDK 35 para compilar APK
- Gradle Wrapper a configurar após validação das versões

## Compilar
A partir de `native/`: `gradle :android:assembleDebug` (requer Android SDK configurado e JDK compatível com Android Gradle Plugin).

Esta primeira entrega é **somente um esqueleto inicial**, ainda sem a máquina de garra, artes ou animações definitivas. Não foi validada em dispositivo Android.
